# Group History by Date

Group history entries by date. Each grouped entry should show the date and the total time spent for that day. Clicking on the grouped entry will bring you to the usual list of entries for that date, with the usual delete controls. Grouped entries should not have delete controls, only a decorative > icon on hover that indicates there are more entries to be viewed.
