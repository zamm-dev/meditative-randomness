# Meditative Randomness

**Meditative Randomness** is a meditation timer app that tracks randomized meditation sessions. Instead of fixing an exact meditative schedule for yourself, open up your meditative practice to the subtle temporal influences of the universe.

Users specify a minimum and maximum time range, and the timer randomly selects a duration within that range. The app keeps track of a running history of completed sessions.
